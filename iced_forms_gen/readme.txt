iced_forms_gen

Утилита для формирования кода приложения из экспортов JSON IcedForms (среда быстрого прототипирования форм для популярной кроссплатформенной библиотеки Iced 0.14 построенная по архитектуре Elm )

Версия продукта:
Прототип. 
Реализовано не все и не везде. Можно создавать простые приложения на основе форм, экспортированых в JSON из IcedForms (тоже прототип)

ПО развивается как ПЭТ проект в рамках изучения Rust. Изначально хотелось получить опыт в построении простого RAD, но вышло то, что вышло

Что сделано:
+ Можно создавать код Rust для простых однооконных форм 
+ Работает в Windows. Для мультиплатформенного переноса необходимо адаптировать некоторые платформозависимые части приложения
