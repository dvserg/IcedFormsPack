IcedForms
Среда быстрого прототипирования форм для популярной кроссплатформенной библиотеки Iced 0.14 построенная по архитектуре Elm

Потенциально должна работать в Windows(+), Linux(+), MacOs(?). 
Реально - пока только в Windows и Linux, в остальных ОС не проверялось

// =============================================================================
Версия продукта:
Прототип. 
Реализовано не все и не везде. Можно создавать простые формы, экспортировать их в JSON для поледующей генерации кода Rust в iced_form_cen (тоже прототип)

ПО развивается как ПЭТ проект в рамках изучения Rust. Изначально хотелось получить опыт в построении простого RAD, но вышло то, что вышло
