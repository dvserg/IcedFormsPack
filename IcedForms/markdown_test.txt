Демонстрационный текст в формате [Markdown](https://wikipedia.org) содержит основные элементы разметки для проверки их отображения. Подробнее о возможностях синтаксиса можно прочитать в статье [Язык разметки Markdown на Доке](https://doka.guide).

## Заголовки
# Заголовок H1
## Заголовок H2
### Заголовок H3

## Текстовые стили
* **Жирный текст** выделяется двойными звёздочками.
* *Курсив* выделяется одинарной звёздочкой.
* ~~Зачёркнутый текст~~ оформляется с помощью тильд.

## Списки и задачи
Маркированный список:
* Первый пункт
* Второй пункт
  * Вложенный пункт

Нумерованный список:
1. Шаг первый
2. Шаг второй

Чек-лист (список задач):
- [x] Выполненная задача
- [ ] Невыполненная задача

## Цитаты
> Блок цитирования используется для выделения важных мыслей или отрывков из сторонних источников.

## Код и таблицы
Пример встроенного кода: `print("Hello, World!")`

Блок кода:
```python
def greet(name):
    return f"Привет, {name}!"
```

## Продвинутые элементы (Расширения)

### Сноски
Здесь находится текст со сноской[^1], которая обычно отображается в самом внизу страницы.

### Математические формулы (LaTeX)
Встроенная формула: $E = mc^2$

Выделенная формула в виде отдельного блока:
$$ \frac{a}{b} = \sqrt{c^2 + d^2} $$

### Спойлер (Раскрывающийся блок HTML)
<details>
<summary>Нажмите, чтобы развернуть спойлер</summary>
Скрытый текст, который поддерживает **Markdown-разметку**.
</details>

[^1]: Это текст самой сноски, который поясняет термин или источник.
